net_speed
=========
  Замеряет скорость скачивания из интернета со своего компьютера
  Принимает параметр url=адрес тяжёлого файла (например, большой картинки)

  Логика работы
  =============
    Последовательно выполняет 10 GET-запросов к указанному адресу (каждый запрос — отдельное соединение)
    Для каждого запроса дожидается полной загрузки ответа, замеряет время и объём полученных данных
    Запросы, завершившиеся ошибкой (таймаут, обрыв, HTTP 4xx/5xx), пропускаются — статистика считается по успешным
    Печатает среднее время запроса, суммарный объём скачанных данных и скорость в МБ/с и Мбит/с

  Параметры
  =========
    url=<адрес>    | обязательный, http:// или https://
    count=<N>      | число запросов, по умолчанию 10
    timeout=<сек>  | таймаут одного запроса, по умолчанию 30

  Единицы измерения
  =================
    1 МБ = 1 000 000 байт, 1 Мбит/с = МБ/с * 8
    Скорость = суммарный объём / суммарное время успешных запросов

  Для запуска программы используйте следующий синтаксис
  =====================================================
    python ./net_speed.py url=https://images-assets.nasa.gov/image/PIA03654/PIA03654~orig.jpg
    python ./net_speed.py url=https://speed.cloudflare.com/__down?bytes=10000000 count=5 timeout=15

  Пример вывода
  =============
    url       | https://images-assets.nasa.gov/image/PIA03654/PIA03654~orig.jpg
    count     | 10
    timeout   | 30 s
    ----------------------------------------
    1  | request  |  3.412 s | 7731939 bytes
    2  | request  |  3.369 s | 7731939 bytes
    3  | request  | error    | HTTP 429 Too many requests
    ...
    10 | request  |  2.625 s | 7731939 bytes
    ----------------------------------------
    success   | 9 / 10
    avg time  | 3.172 s
    total     | 69587451 bytes (69.59 MB)
    speed     | 2.44 MB/s
    speed     | 19.50 Mbit/s

  Тесты (без доступа в интернет, на локальном HTTP-сервере)
  =========================================================
    python -m unittest test_net_speed -v
